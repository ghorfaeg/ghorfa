# Ghorfa website
1. Put photos in `images/` (e.g. `desk-150-1.jpg`).
2. Open `products.js`, list the file names in `images`, set `price`, edit details.
3. Set your WhatsApp number, Instagram and Facebook links at the top of `products.js`.
4. Upload everything to your GitHub repo (Settings → Pages → deploy from `main`).
